## 六、命名体系（值得保留的一致性）

这套设定里，名字都不是随手起的，建议后续沿用同一逻辑：

| 意象 | 用词 | 含义链 |
|---|---|---|
| **逆流 / 回溯** | 溯黎、洄 | 溯＝逆流而上，洄＝回旋之水；整个文明的名字就是"往回看" |
| **侵蚀 / 消耗** | 蚀、侵蚀、腐化 | 恒星名与灾害名同源，暗示"发光的东西也在吃掉你" |
| **风** | 防风、Zephyr、风暴纪元、c3Y | 人、史、企划三层共用一字，是母题 |
| **方位 / 天** | 北辰、神舟 | 北辰＝北极星，神舟＝渡天之舟，都在"天"这一层 |

> 唯一没跟上这套逻辑的是 **九翎**——"翎"属鸟羽，与"风"勉强能接（翎管可作风哨），但与"水／天／石"体系不同源。◇ 可作为"他来自另一条脉络"的暗示，也可以改。

## 七、需要立刻统一的 5 处写法

1. **古琴 / 古筝** → 建议统一为 **古琴**（脑图＋设定0 均为古琴，docx 为早期稿）。
2. **溯黎 / 前文明** → 叙述用"前文明"，专名用"溯黎"，首次出现写"前文明溯黎"。
3. **小屏幕 / 终端 / 晶石** → 三层关系固定为：晶石（本体）＞ 终端（外壳）＞ 小屏幕（防风那一台）。
4. **数据库** → 不再单独出现，改说"晶石里存的年轮"。
5. **纪元顺序** → 火 → 晶硅 → 风暴，任何地方不得倒置；"风暴纪元"与"c3Y（风暴）"要明确是巧合还是命名来自史实（◇ 建议：企划名取自史上那场风暴）。
